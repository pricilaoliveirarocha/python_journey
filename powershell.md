# Comandos do PowerShell importantes no dia a dia 🌸

- `mkdir nome_diretorio` - Cria um novo diretório.

- `cd nome_diretorio` - Muda o diretório atual para o especificado.

- `Get-ChildItem` - Lista os arquivos e diretórios em um caminho.

- `.\.php\php.exe -S localhost:8000` - Inicia um servidor PHP embutido na porta 8000.

- `php --version` - Exibe a versão do PHP instalada.

- `uvicorn basics:app --reload` - Inicia um servidor Uvicorn para uma aplicação FastAPI com recarregamento automático (dentro de um ambiente virtual ou da pasta com o python).

- `.\.venv\Scripts\Activate.ps1` - Ativa o ambiente virtual do Python no PowerShell.
